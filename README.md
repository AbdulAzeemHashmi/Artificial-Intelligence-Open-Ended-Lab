# 🤖🎥 Artificial Intelligence Open Ended Lab

Welcome to the **Artificial Intelligence Open Ended Lab** repository! ✨

<div align="center">
<img src="https://user-images.githubusercontent.com/74038190/213910845-af37a709-8995-40d6-be59-724526e3c3d7.gif" width="450">
</div>

This repository contains the implementation of a comprehensive AI video processing pipeline. The project leverages state of the art machine learning models to analyze video footage, detect objects, generate frame captions, and evaluate scene impact scores 📊.

---

## 📂 Repository Contents

| File | Description |
|---|---|
| 📓 `AI_OEL.ipynb` | Main Jupyter Notebook with the complete Python codebase and pipeline implementation for all tasks |
| 🎬 `Task1_ROI_Processing.mp4` | Video output showing Region of Interest extraction and processing |
| 🎬 `Task3_Raw_Selection.mp4` | Video output showing raw scene and segment selection |
| 🎬 `Task4_Creepy_Visuals.mp4` | Video output showing advanced visual processing effects |
| 🎬 `Task5_Final_Trailer.mp4` | Final compiled trailer generated by the pipeline |
| 📈 `Task6_Evaluation_Graph.png` | Data visualization plot showing the Scene Impact Score Timeline evaluated by the ML model |

This project utilizes several powerful libraries and AI models:

* 🎯 **YOLO11, Ultralytics:** For high speed, real time object detection and tracking within the video frames
* 🖼️ **BLIP, Bootstrapping Language Image Pre training:** For generating rich, contextual captions and understanding the scenes
* 🎞️ **MoviePy and OpenCV:** For video manipulation, audio extraction, and frame by frame processing
* 🔥 **PyTorch:** Deep learning framework powering the AI models
* 📊 **Matplotlib:** For generating evaluation and impact score graphs

## 🚀 Lab Tasks Overview

The pipeline executes a series of sequential tasks to analyze the videos:

<details>
<summary>🧩 <b>Task 1 : ROI Processing</b> - click to expand</summary>
<br>
Extracts and processes specific Regions of Interest, ROI, from the video feed.
</details>

<details>
<summary>🧠 <b>Tasks 2 to 5 : Advanced Video Analysis</b> - click to expand</summary>
<br>
Utilizes YOLO11 to track objects and BLIP to generate semantic understanding of the video segments.
</details>

<details>
<summary>📉 <b>Task 6 : Scene Impact Score Evaluation</b> - click to expand</summary>
<br>
Calculates a raw impact score for each video segment. The final output generates a timeline graph, `Task6_Evaluation_Graph.png`, plotting these scores against a median High Impact Threshold.
</details>

## ⚙️ How to Run

**Step 1 : Clone this repository**

```bash
git clone https://github.com/AbdulAzeemHashmi/Artificial-Intelligence-Open-Ended-Lab.git
cd Artificial-Intelligence-Open-Ended-Lab
```

**Step 2 : Install dependencies**

```bash
pip install ultralytics torch torchvision moviepy opencv-python matplotlib transformers
```

**Step 3 : Open the notebook**

```bash
jupyter notebook AI_OEL.ipynb
```

**Step 4 : Run all cells in sequence** ▶️

Follow the pipeline from Task 1 through Task 6 to reproduce the processed reels and the evaluation graph 🎉
